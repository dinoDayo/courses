# Splink Notes
- Splink is a highly customizable pyspark-based tool designed to provide fast, accurate and probabalistic record linkage that is easily explainable and highly scalable for larger datasets. [Learn more from their documentation here.](https://moj-analytical-services.github.io/splink/)
    - NOTE: There are also quite a few high quality overviews of how the tool works on youtube if you search `splink`. They are based out of the UK so you can use that as a heuristic when filtering the results.
- The example splink python (`example_splink.py`) file is pulled directly from the splink tutorial and assumes you have installed `splink` to your local environment. [View the complete tutorial here.](https://moj-analytical-services.github.io/splink/getting_started.html)
